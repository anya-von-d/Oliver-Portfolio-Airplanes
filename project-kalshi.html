Project

Kalshi Latency Arbitrage Trading Bot

Python Trading Systems Real-Time Data Kalshi API

Developed a low-latency algorithmic trading system for Kalshi prediction markets that identifies and executes latency arbitrage opportunities by exploiting temporary pricing discrepancies between exchange-traded cryptocurrency prices and event contract markets. Engineered a real-time market data pipeline integrating live cryptocurrency price feeds with Kalshi order book data to detect statistically significant pricing inefficiencies within sub-second time windows. Implemented automated signal generation, execution logic, risk management, and position sizing while optimizing network latency, asynchronous processing, and order placement speed to maximize capture of rapidly decaying arbitrage opportunities.
